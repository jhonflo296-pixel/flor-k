# 🌻 Galaxia de Flores Amarillas para Mi Mejor Amiga

Una experiencia interactiva 3D con Three.js dedicada con mucho cariño para mi mejor amiga en el Día de las Flores Amarillas.

✨ **Características:**
- Agujero negro central con resplandor dorado y anillo estilo Saturno.
- Girasoles y ramos de flores amarillas flotando en el espacio 3D.
- 30 frases especiales dedicadas a una gran amistad.
- Canción de fondo incluida con control de reproducción.
- Compatible con móviles, tablets y computadoras.
